VTU24676 - Campus Notification Dashboard

Overview

This project is a React-based Campus Notification Dashboard developed for the Frontend Evaluation.

The application fetches notifications from the provided evaluation API and displays them in a clean user interface with filtering and pagination support.

Features

* View campus notifications
* Filter notifications by type
* Pagination support
* Responsive UI using React and CSS
* API integration using Fetch API
* Logging middleware integration

Technologies Used

* React
* JavaScript
* Vite
* HTML
* CSS
